# UI fonts

Current UI: Departure Mono v1.500 by Helena Zhang, unmodified official binary. Its distinct open G,
barred 5 and consistent numerals replace Pixelify Sans for clarity. Use 22/33/44 px at 100/150/200%,
multiples of the native 11 px grid; no grayscale antialiasing/subpixel positioning. Smaller decorative
sizes must not carry essential combat data. Keep the supplied DepartureMono-LICENSE.txt with exports.

Official binary/source: https://github.com/rektdeckard/departure-mono/tree/main/public/assets
Author specimen: https://departuremono.com/

Pixelify Sans and OFL.txt remain for historical art previews. New shared kit previews use Departure
Mono. Unsupported characters retain the engine's system fallback; check localization before expansion.
